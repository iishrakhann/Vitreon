# EMS2 Major Presentation Plan

## Audience

- Faculty evaluators
- Project guide
- Viva or demo panel

## Objective

- Create a detailed major-project PowerPoint that follows the requested chapter order and extends beyond 15 slides.

## Narrative Arc

1. Introduce EMS2 and its real-world problem.
2. Explain the manual existing system and the need for the proposed platform.
3. Cover scope, operating environment, and technologies used.
4. Show representative application screens.
5. Finish with the key analysis and design diagrams.

## Slide List

1. Title page
2. Introduction
3. Existing system
4. Need for the proposed system
5. Scope of work
6. Hardware environment
7. Software environment
8. Core technologies
9. Supporting technologies
10. Screens: home and venues
11. Screens: detail, auth, dashboard
12. System flow diagram
13. Use case diagram
14. Class and design view
15. Sequence and activity view
16. Deployment diagram
17. Website map and closing note
